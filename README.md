# Lista de Compras

Este projeto implementa um sistema simples de lista de compras usando HTML, CSS e JavaScript.

## Usar o sistema

1. Abra o arquivo `index.html` no navegador.
2. Digite o nome do item no campo de entrada.
3. Informe a quantidade e selecione a unidade de medida (kg, litros, gramas, pacote, etc.).
4. Clique em **Adicionar** ou pressione Enter.
5. Marque itens como comprados ou exclua-os.
6. Use **Limpar lista** para apagar todos os itens.

## Arquivos

- `index.html` - interface do usuário.
- `style.css` - estilos visuais.
- `script.js` - lógica de adicionar, marcar e remover itens.

Os itens são salvos automaticamente no `localStorage` do navegador para manter a lista mesmo após recarregar a página.
